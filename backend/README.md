# Backend Server

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the server:
```bash
npm start
```

For development with auto-reload:
```bash
npm run dev
```

The server will run on `http://localhost:3001`

## API Endpoints

- `POST /api/button/click` - Handles button click events
- `POST /api/button/longpress` - Handles button long-press (2 seconds) events
